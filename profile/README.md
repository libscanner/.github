## Scanner — DataMatrix libraries for product marking

Commercial C++ libraries for **reading** and **generating** GS1 DataMatrix codes — built for conveyor lines,
industrial cameras and Chestny ZNAK, the Russian product marking system. C++20 API, flat C ABI, Python wheels
and a command-line tool; Windows x64 and Linux x86-64 / ARM64 / ARMv7 (Raspberry Pi).

| | |
|---|---|
| **[datamatrix-reader](https://github.com/libscanner/datamatrix-reader)** | Reads GS1 DataMatrix from industrial camera frames: 99.6% of 8,959 production-line frames read with no false reads, 7 ms median per frame. · [Docs](https://libscanner.com/en/docs/datamatrix-gs1/) · [Try online](https://libscanner.com/en/scan) |
| **[datamatrix-generator](https://github.com/libscanner/datamatrix-generator)** | Generates DataMatrix ECC 200 (ISO/IEC 16022) with GS1 and Chestny ZNAK validation, PNG and JPEG for printing. · [Docs](https://libscanner.com/en/docs/datamatrix-generator/) · [Try online](https://libscanner.com/en/generate) |
